- [x] TXT 导入器：编码识别（BOM/UTF-8/GBK）、清洗、切章正则 + 字数兜底，单元测试；

- [x] EPUB 导入器：zip 头校验、拷贝落盘；
- [x] `web_capture` + `web_article_importer`：URL 校验、隐藏 WebView 抓取、重试、错误态区分（网络失败 / 提取为空）、切章、快照、重抓；

- [x] 「重新抓取」入口与「文件缺失」态；

- [x] `reader_history` / `reader_log` 埋点写入（阅读活动与时长），单测覆盖聚合。

### 准出条件
