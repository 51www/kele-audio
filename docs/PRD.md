## 1. 项目概述

### 1.1 产品定位

一款**安卓端有声内容收听应用**，内容源为 B 站（哔哩哔哩）的视频/音频资源，通过"只听声音"的方式为用户提供：

- 成年人内容：有声书、评书、相声、讲书、小说、音乐、播客、英语听力等；
- 儿童内容：绘本、儿歌、童话、睡前故事等（"儿童模式"）。

应用定位为**个人/小范围使用工具**，非公开发行产品。

### 1.2 核心价值

1. 把 B 站丰富的长音频内容变成"随身听"体验（锁屏、后台、断点续播）；
2. 结构化的内容组织（专辑-章节模型），替代 B 站原始的视频流浏览方式；
3. 一键切换的儿童模式（儿童向 UI 主题 + 白名单内容过滤），满足家庭共用一台设备的场景。

### 1.3 产品目标

- MVP 阶段目标：完成"发现 → 收藏 → 播放 → 断点续播 → 儿童模式切换"主链路闭环；
- 质量目标：播放稳定、切后台不中断、重启后能续播。

### 1.4 非目标（明确不做）

- ❌ 不做用户间社交（点赞、评论、分享站内）；
- ❌ 不做防沉迷、家长控制等儿童监管类功能（儿童模式仅为主题 + 内容过滤）；
- ❌ 不做自建后端、账号体系（B 站登录仅作为可选增强，见 §7.6）；
- ❌ 首期不做 iOS、不做应用商店上架。

## 2. 技术难点与风险点（先读这一章）

> 按严重程度排序。每个风险均给出应对策略，后续功能设计均以此为约束前提。

### R1. 【高】B 站无官方开放接口，接口随时可能失效

- **描述**：B 站没有面向第三方的公开 API，本项目使用的是其 Web 端内部接口（`api.bilibili.com`）。核心接口自 2023 年起要求 **WBI 签名**（从 `nav` 接口取 key 后做混淆签名），签名算法、参数、接口路径都可能被随时升级。
- **影响**：一旦接口变更，App 的搜索、取播放地址、登录等功能会整体瘫痪，且无法通过服务端热修复（因为没有自建后端）。
- **应对策略**：
  1. **API 层隔离**：所有接口调用收敛到独立的 `api` 模块，接口路径/签名逻辑集中管理，禁止散落在业务代码中；
  2. **接口配置可下发**：预留"远程接口配置"能力（可挂 GitHub Raw / 任意静态托管 JSON），配置内容包括接口路径映射、参数模板、签名算法版本号，便于紧急修复时无需发版；
  3. **降级兜底**：核心接口失败时给出明确提示与重试入口，避免白屏；
  4. 关注 `bilibili-API-collect` 等社区逆向文档，跟进签名算法变化。

### R2. 【高】风控与限流（-412 / 403 / 临时封禁）

- **描述**：B 站对高频、特征异常的请求有风控。匿名接口依赖 `buvid3` 等设备指纹 Cookie；请求过快、缺少 Referer/UA 等头信息时会返回 -412。
- **影响**：功能不可用；若关联账号，可能影响用户个人 B 站账号。
- **应对策略**：
  1. 全局请求节流（搜索类接口建议 ≥ 1s 间隔，播放地址获取按需即取）；
  2. 搬运浏览器标准请求头（UA、Referer、Origin）与必要 Cookie，保持"像浏览器"的特征；
  3. 本地缓存封面、搜索结果、合集列表（TTL 缓存），减少重复请求；
  4. 失败时指数退避重试，不自动高频重试；
  5. 登录态仅用于提升音质等增强场景，风控风险由用户自担（见 §7.6）。

### R3. 【高】内容版权与分发风险

- **描述**：有声书、评书、相声类内容的版权方通常不是上传 UP 主（盗版重灾区），本 App 实质是在聚合播放这些内容。B 站用户协议亦禁止未经授权的抓取。
- **影响**：个人自用风险低；**一旦公开分发、商业化或扩大影响范围，侵权风险显著上升**。
- **应对策略**：
  1. 产品定位保持"个人工具"，不做公开推广；
  2. 仅做"播放跳转/在线收听"，**不做内容的二次转码分发**；
  3. 离线缓存功能设计为用户本地行为，并在《关于》页明示内容版权归原作者/平台所有（见 §12）。

### R4. 【中】内容分类与儿童内容筛选无官方元数据

- **描述**：B 站没有"有声书"标准分类，也没有任何年龄分级标注。发现页的分类体系、儿童模式的内容过滤全部需要自建。
- **影响**：分类质量直接决定产品体验；儿童模式过滤不准会推给用户不相关内容。
- **应对策略**：
  1. **内容源优先选"封闭形态"**：合集/系列、多 P 视频天然形成稳定 ID 列表，不存在搜索漏出的问题；
  2. 三级筛选信号组合：**UP 主白名单（主信号）→ 关键词/标签（辅助信号）→ 人工终审**；
  3. 儿童内容库与成人内容库分开维护（两份白名单配置，可本地/远端配置下发）；
  4. 分类与白名单运营成本按"每周 ≤ 1 小时"设计，避免过度工程。

### R5. 【中】音频流地址时效性与 Referer 校验

- **描述**：DASH 播放地址为带时效签名的 CDN URL（数小时过期），部分 CDN 校验 Referer。地址不可持久化。
- **影响**：离线缓存、断点续播、长音频中途续播时若直接复用旧 URL 会 403。
- **应对策略**：
  1. 播放前实时换取地址，**URL 只存内存不落库**；
  2. 播放器监听 403/超时错误 → 自动重新换取地址 → 无缝续播（seek 到原进度）；
  3. 离线缓存使用下载时落盘的实体文件，与在线播放是两条独立链路。

### R6. 【中】Flutter 音频体验的工程细节

- **描述**：听书类 App 的核心体验在播放链路：后台播放、锁屏控制、音频焦点（来电/导航打断）、耳机线控、断点续播、定时关闭、倍速。Android 还涉及前台服务、电池优化白名单等系统配置。
- **影响**：任一环节做不好，用户会直接感知为"不好用"。
- **应对策略**：
  1. 采用成熟组合：`just_audio`（播放内核，ExoPlayer）+ `audio_service`（后台服务/锁屏通知）+ `audio_session`（音频焦点）；
  2. 播放状态与进度**每 15~30s 持久化一次**（本地 SQLite/Hive），进程被杀后可续播；
  3. 章节切换（多 P / 合集分章）时预取下一章播放地址，减少切章卡顿；
  4. 对国产 ROM 的后台限制做适配测试（小米/OPPO/vivo/华为）。

### R7. 【低】音频格式与流量

- **描述**：DASH 音频流为 m4a（64k/132k/192k），Hi-Res 为 FLAC（需大会员）。不经过转码。
- **应对策略**：默认 132k/192k，提供"省流音质"选项；m4a 为 ExoPlayer 原生支持，无需引入 ffmpeg（可显著减小包体积）。

### R8. 【低】离线缓存的存储管理

- **描述**：整本书缓存可能达数百 MB~GB 级，涉及清理、配额、断点续传。
- **应对策略**：缓存管理页展示占用空间、单集删除/全量清理、仅 Wi-Fi 下载开关。

### 风险总览表

| 编号 | 风险 | 等级 | 是否阻塞 MVP |
|---|---|---|---|
| R1 | 接口无官方保障，随时改版 | 高 | 否（但需架构预留热修复） |
| R2 | 风控限流 | 高 | 否 |
| R3 | 内容版权 | 高 | 否（限个人使用） |
| R4 | 分类/儿童筛选自建 | 中 | 否 |
| R5 | 播放地址时效性 | 中 | 是（必须实现自动重签续播） |
| R6 | 播放器工程细节 | 中 | 是（后台/续播属 MVP） |
| R7 | 音频格式 | 低 | 否 |
| R8 | 存储管理 | 低 | 否（可放二期） |

## 5. 功能需求详述

### 5.1 发现页（Tab 1）

**目标**：让用户 3 步内找到想听的内容（选类型 → 选专辑 → 播放）。

#### 5.1.1 页面结构（自上而下）

1. **顶部栏**
   - 左：应用 Logo / 儿童模式状态图标（开启时显示）；
   - 右：搜索入口（**MVP 可隐藏，二期开放**，见 §11）、儿童模式切换开关。
2. **内容类型分类 Tab（横向滚动）**

   成人模式下的分类（初始集，可运营配置）：

   | 分类 | 内容源说明 |
   |---|---|
   | 推荐 | 默认 Tab，混排各类型的优质内容 |
   | 有声书 | 长篇小说、原著朗读（多 P / 合集） |
   | 相声曲艺 | 相声、评书、大鼓等 |
   | 讲书 | 解说类、知识类节目 |
   | 音乐 | 歌曲、纯音乐、演唱会现场 |
   | 播客 | 对谈/访谈类播客节目、电台谈话 |
   | 英语听力 | 英语听力材料、VOA/BBC 等外语学习音频 |
   | 儿童 | **仅在儿童模式下出现**，或成人模式下作为普通分类存在（二选一，见开放问题 Q1） |

   儿童模式下的分类：`绘本 | 儿歌 | 童话故事 | 睡前故事 | 科普`（白名单内容）。

3. **推荐位 Banner（可选，MVP 可用"编辑精选"列表替代）**：轮播 3~5 个推荐专辑。
4. **内容卡片流**
   - 卡片要素：封面图（宽高比 3:4 或 1:1）、标题、UP 主名称、时长/章节数、播放量；
   - 布局：双列瀑布流或网格（MVP 建议**规整双列网格**，实现简单）；
   - 点击卡片 → 专辑详情页。

#### 5.1.2 交互与状态

- 下拉刷新；分页加载（页码/offset，触底自动加载下一页）；
- 加载骨架屏（Skeleton）；空状态（"该分类暂无内容"）；错误态（含"重试"按钮）；
- 分类切换时本地缓存该分类第一页，二次进入秒开（TTL 建议 30 分钟）。

#### 5.1.3 数据要求

- 每个分类对应一组**可配置的内容源查询条件**（见 §7.2），支持后续不发版调整分类内容。

### 5.2 专辑详情页

**目标**：展示专辑全部章节，支持收藏与整本播放。

- 内容：封面、标题、简介、UP 主、总章节数、总时长、收藏按钮、"播放全部"按钮；
- **章节列表**：
  - 多 P 视频 → 每个分 P 为一章；
  - 合集/系列 → 每个视频为一章；
  - 列表项：序号、章节标题、时长、**收听进度标记**（未听/在听/已听完）；
  - 点击某章 → 播放该章；
- 收藏/已收藏 状态切换（写入书架，见 §5.3）；
- 长列表章节需分页/懒加载。

### 5.3 书架（Tab 2）

**目标**：管理已收藏内容，快速回到在听的内容。

1. **在听置顶区**：展示最近 30 天内有播放记录且未听完的专辑（卡片 + 进度条），点击直接续播；
2. **收藏列表**：
   - 卡片：封面、标题、章节进度（如 `已听 12/86 集`）、最后收听时间；
   - 排序：最近收听 / 收藏时间 / 标题（默认最近收听）；
   - 支持**长按多选删除**、左滑删除；
   - 分页加载；
3. **空状态**：引导文案 + 跳转发现页按钮；
4. 收藏数据**仅存本地**（无账号同步，见 §7.6）；
5. 支持儿童模式下显示（收藏不分模式，内容一致）。

### 5.4 播放页（核心页面）

**目标**：听书场景下的完整播放控制。

#### 5.4.1 页面元素

- 顶部：折叠返回、更多菜单；
- 中部：专辑封面（黑胶/CD 旋转动效可选）、专辑标题、章节标题、章节进度（`第 12 章 / 共 86 章`）；
- 进度条：可拖拽 seek，显示当前/总时长；
- **控制区**：播放/暂停、上一章/下一章、播放模式（顺序/列表循环/单曲循环）；
- **功能区（听书刚需）**：
  - 倍速：0.5x ~ 3.0x（步进 0.1，常用档 0.75/1.0/1.25/1.5/2.0）；
  - 定时关闭：关闭 / 5 / 10 / 15 / 30 / 45 / 60 分钟 / 本章结束；
  - 章节列表抽屉（底部弹出，显示进度，快速跳章）；
  - 音质切换（64k / 132k / 192k，见 R7）；
- 底部：加入书架按钮。

#### 5.4.2 播放行为要求（MVP 必须）

| 编号 | 要求 |
|---|---|
| P-01 | 支持后台播放：锁屏、切后台、来电话中断后自动恢复 |
| P-02 | 锁屏/通知栏展示封面、标题、播放控制（播放/暂停/上下章） |
| P-03 | 断点续播：进度每 15~30s 持久化，杀进程/重启后回到原进度 |
| P-04 | 跨章续播：专辑内切章后，返回再进入该专辑默认定位到"最后听的章节" |
| P-05 | 播放地址失效（403/超时）自动重取地址并续播（R5） |
| P-06 | 耳机线控、蓝牙耳机按键控制（播放/暂停/上下章） |
| P-07 | 音频焦点：导航语音播报时自动压低/暂停，结束后恢复 |
| P-08 | 倍速、定时关闭在杀进程后恢复默认（不持久化倍速可接受，见开放问题 Q3） |

### 5.5 儿童模式（全局状态）

**目标**：一键切换到儿童向 UI + 白名单内容；操作方式与平时无异。

1. **入口**：发现页顶部开关（图标明显，建议"小熊/气球"类图标）；
2. **开启后变化**：
   - 全局主题切换为儿童主题（高饱和配色、圆角卡片、大图标、插画风）；
   - 发现页分类替换为儿童分类，内容全部来自**儿童白名单库**（R4）；
   - 书架、我的**页面结构不变**，仅换主题；
   - 播放页不变（仅换主题）；
3. **关闭**：同一开关切回（建议二次确认弹层，避免误触）；
4. **不改变**：收藏、历史、设置的可用性——儿童模式只是"皮肤 + 内容过滤"，不做操作限制；
5. 白名单配置支持本地内置 + 远端配置覆盖（见 §7.3）。

### 5.6 我的（Tab 3）

#### 5.6.1 页面结构

1. **顶部用户区**：头像占位、昵称（未登录显示"未登录"，登录后显示 B 站昵称，见 §7.6）、累计收听时长摘要；
2. **听书统计**
   - 今日/本周/本月收听时长（柱状图或数字卡片）；
   - 累计收听时长、累计听完专辑数；
   - 收听排行：最常听的分类 Top3、最常听的专辑 Top5；
   - 连续收听天数（可选）；
   - 数据来源：本地播放日志聚合，**不上传任何服务器**；
3. **功能入口列表**：
   - 历史收听 → 二级页（§5.7）；
   - 离线缓存 → 二级页（§5.8）；
   - 设置 → 二级页（§5.9）；
   - 关于/版本 → 二级页（§5.10）。

#### 5.6.2 历史收听页（§5.7）

- 列表：封面、标题、最后播放章节与进度、时间（今天/昨天/日期分组）；
- 支持单条删除、清空历史；
- 点击 → 续播；
- 分页加载。

#### 5.6.3 离线缓存管理页（§5.8）

- 展示总占用空间；提供"仅 Wi-Fi 下载"开关、缓存上限设置（可选）；
- **仅播放已缓存文件，离线状态下可正常收听**（MVP 可只做"整本缓存"，单集缓存放二期）。

#### 5.6.4 设置页（§5.9）

## 7. 技术架构建议（支撑上述需求）

### 7.1 分层结构

```
lib/
├── app/            # 路由、主题、DI
├── features/       # 按功能分模块
│   ├── discover/   # 发现
│   ├── shelf/      # 书架
│   ├── profile/    # 我的
│   ├── player/     # 播放
│   └── children/   # 儿童模式（主题+白名单）
├── core/
│   ├── api/        # ⚠️ B 站接口层（隔离，含 WBI 签名、接口配置）
│   ├── data/       # 本地存储（SQLite/Hive）、缓存
│   ├── domain/     # 专辑/章节实体、用例
│   └── services/   # 播放服务、下载服务、统计服务
```

### 7.2 内容源模型（发现页分类的落地方式）

每个"分类"本质是一组**查询配置**（JSON，可远端下发）：

```json
{
  "category_id": "xiaoshuo",
  "name": "有声书",
  "mode": "adult",
  "queries": [
    { "source": "search", "keyword": "有声小说", "order": "click", "scope": "video" },
    { "source": "up_mid", "up_mids": [123, 456], "order": "pubdate" },
    { "source": "series", "series_ids": [789] }
  ],
  "blacklist_up_mids": []
}
```

- `source=search`：按关键词搜索（辅助）；`up_mid`：指定 UP 主新作（主信号，质量最稳）；`series/合集`：封闭内容列表（最稳）；
- 组合策略：**优先合集/UP 主，搜索结果补充**，并做黑名单过滤。

### 7.3 儿童白名单库

- 独立配置文件（同 §7.2 结构，`mode: "children"`）；
- 内置一份默认白名单随包发布，支持远端配置覆盖（更新无需发版）；
- 远端配置托管：任意静态托管（GitHub Raw 等），**注意 R1 中提到的"无自建后端"限制，静态 JSON 即可满足**。

### 7.4 播放链路

```
专辑(合集/多P) → 章节列表 → 选择章节
   → api 换取 DASH 播放地址（实时，不落库）
   → just_audio 播放（m4a 流）
   → audio_service 前台服务 + 锁屏通知
   → 进度/章节状态 → 本地 SQLite 持久化
```

### 7.5 本地数据（草案）

| 表 | 关键字段 |
|---|---|
| `album`（专辑缓存） | id, source_type, title, cover_url, up_name, chapter_count, category_id |
| `chapter`（章节） | id, album_id, index, title, duration, bvid/cid |
| `shelf`（书架） | album_id, created_at |
| `play_history` | album_id, chapter_id, position_sec, duration, played_at |
| `play_log`（统计用） | date, album_id, category_id, duration_sec |
| `download` | chapter_id, file_path, size, status |

### 7.6 关于 B 站登录（可选增强）

- **默认匿名使用**（搜索、播放、合集均支持匿名）；
- 登录（扫码）仅用于：访问需登录接口、获取更高音质（如 Hi-Res）；
- 登录态仅存本地，不做账号池、不做任何代登录；
- MVP 可完全不含登录，二期再评估。

## 10. 验收标准（MVP）

1. 断网状态下，书架/历史可打开，已缓存内容可播放；
2. 播放中锁屏可控制；杀掉进程后重启 App，能回到原专辑原章节原进度；
3. 播放中拔掉 Wi-Fi 切 4G（或地址过期）不中断播放；
4. 儿童模式开启后，发现页内容 100% 来自儿童白名单；关闭后恢复正常；
5. 收藏 → 重启 App → 书架仍在；
6. 3 个 Tab 切换保留滚动状态与 MiniPlayer 不丢失。
