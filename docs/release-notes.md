# 版本更新记录

> 分类命名统一为：**新增功能 / 功能优化 / 问题修复**。版本号、Git Tag（`vX.Y.Z`）、Release 标题三处保持一致。

## v1.2.0（2026-10-30）

### 新增功能

- **客户端检查更新（GitHub Releases）**：关于页新增「检查更新」入口，手动触发；Android 走完整闭环（检查 → 下载 → 安装），Web 仅保留仓库链接不接逻辑；**永不强制**，任何阶段可取消/关闭。
  - 数据源 `api.github.com/repos/51www/kele-audio/releases/latest`，带 `User-Agent`、连接 12s / 传输 20s 超时；版本比较去 `v` 前缀与 `-beta` 后缀按段数值比较，同版本/更旧一律不提示。
  - 产物选择：Android 优先 `*-android-universal.apk`，兼容历史 `app-release.apk`，排除 `.aab`。
  - 国内镜像加速：下载回退顺序「镜像在前 → GitHub 官方直连兜底」，接口顺序「官方优先 → 镜像兜底」；支持 `--dart-define=UPDATE_MIRROR=https://你的镜像/`（逗号分隔，排最前），镜像失效无需发版。
  - 安全：下载完成后用 GitHub asset 的 `sha256:` digest 校验文件哈希，不匹配换源重下，digest 缺失则跳过校验不阻断。
  - 影响范围：平台 Android / Web；新增文件 `lib/features/update/*`；新增依赖 `package_info_plus`；Android 新增 `REQUEST_INSTALL_PACKAGES` 权限与 `FileProvider`（`${applicationId}.fileprovider`），`res/xml/file_paths.xml` 覆盖 files/external-files/cache 目录。

### 功能优化

- 无。

### 问题修复

- 修正「关于 / 版本」硬编码版本号与 pubspec 不一致（原硬编码 `1.0.0`，实为 `1.1.0`）：改为运行时读取 `PackageInfo` 真实版本作为比对基准，避免「已是最新」误判及自报有新版本。

## v1.1.0（2026-10-29）

### 新增功能

- 播放页新增「文稿」：功能图标带的「播放顺序」按钮替换为「文稿」开关，打开后上区（封面）切换为「顶端固定标题 + 可滚动文稿」浏览视图（仅浏览，不联动播放进度）；文稿来自 B 站人工 / AI 字幕（AI 字幕需绑定 B 站账号），仅内存缓存不落库，无字幕章节显示「本章暂无文稿」空态。
- 播放模式不再支持播放页切换，统一由设置页「默认播放模式」决定。

### 功能优化

- 专辑详情页「播放全部」：点击后立即进入播放页，装载/取址与页面转场并行进行，消除「播放条先弹出 → 再跳转播放页」的两段式突兀体验；播放页装载期间显示「正在准备播放…」过渡态，不再闪过「未选择内容」空态。
- 统一播放入口语义：只有专辑详情页「播放全部」会跳转播放页；书架页（在听/收藏）、历史收听页、详情页点单集等入口均改为就地弹出播放条并直接播放，不再自动跳转页面。进入播放页统一通过点击播放条完成。
- 桌面端与移动端表现一致。
