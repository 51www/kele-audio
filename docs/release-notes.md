# 版本更新记录

> 分类命名统一为：**新增功能 / 功能优化 / 问题修复**。版本号、Git Tag（`vX.Y.Z`）、Release 标题三处保持一致。

## v1.4.1（2026-11-08）

### 新增功能

- 本地书导入支持 MOBI / AZW：解析 PalmDB / PalmDOC 文本层与 EXTH 书名、作者，转成内部 EPUB 后复用现有阅读、朗读、进度与备份链路；DRM 加密、HUFF-CDIC 压缩及 AZW3 / KF8 暂不支持，导入时会提示先转换为 EPUB / TXT。MOBI / AZW 导入会提取封面（优先用 EXTH 129 封面图记录，缺失时取书中面积最大的图片作为封面，避免误取正文内嵌插图）并显示在书架。

### 功能调整

- 下线「自定义 HTTP 朗读」与「MiMo 朗读」：听书仅保留系统朗读与 Edge 在线朗读两档；相关模板、音色与 API Key 配置项一并移除，旧版本残留的 Key 会在读取设置时自动清除。
- 移除设置页「缓存」栏目与「进入书籍默认继续听书」开关：进入本地书默认静读，需要朗读时点右上角耳机；离线缓存入口与断点续听能力保持不变。

### 功能优化

- 沉浸阅读（隐藏工具栏）时左上角常驻显示当前章节名与全书进度：落在页眉留白处，顶部渐隐衬底保证滚动模式下也清晰，不影响翻页手势；PDF 显示对应页码段。
- 本地书朗读改为按「一两句话」的短片段合成：首次请求文本更短、出声更快，首片段不再被预合成请求抢占；朗读高亮同步缩小到当前短句，段落断点与进度口径保持不变。
- 听书播放页的「朗读引擎」弹窗扩展为「朗读引擎与音色」：可直接切换系统 / Edge 并挑选音色，切换后即时重读当前段，无需返回设置页；系统音色改为只读探测，不会打断正在朗读的会话，切回「跟随系统默认」也能即时生效。

### 问题修复

- 修复本地书沉浸阅读（隐藏工具栏）时页脚页码与阅读背景对比不足、难以辨认的问题：页码改用当前主题的次级文字色，并去掉渲染器默认的透明度衰减。
- 修复本地书翻页到章节边界时跨章翻不动的问题：章末/章首恢复足够的拖动余量，切章失败可回弹重试，异常时不再锁死翻页。
- 修复听书播放页切换音色 / 语速后，Edge 预合成缓存仍可能播出旧参数音频的问题：预合成结果按会话代际失效，切章、暂停、停止时一并清理在途请求。
- MOBI 大文件解析改到后台 isolate，导入不再阻塞界面；朗读期间播放状态按段维护，减少短句间的界面重建，也避免段间状态抖动导致误触重新起播。

## v1.4.0（2026-11-06）

### 新增功能

- 新增「本地书」：支持导入 TXT、EPUB 与公众号/网页文章链接，书架新增独立分区，可查看阅读进度、按最近阅读/导入时间/标题排序，支持删除与撤销。
- 新增阅读页：支持分页与滚动两种阅读方式，可调整字号、行距、边距与字重，配色跟随当前主题与儿童模式；提供章节目录、阅读进度与断点续读。
- 新增听书：本地书可直接朗读，支持系统朗读与 Edge 在线朗读两种方式；朗读时正文段落自动高亮并跟随滚动，支持语速/音调调整、上一段/下一段、睡眠定时与断点续听。
- 听书支持后台与锁屏播放：退出阅读页或锁屏后继续朗读，可在通知栏与锁屏控制暂停、继续、上一段、下一段与停止。
- 设置页新增「本地书 · 听书」分组：可选择朗读方式与音色、试听、检查网络连通性，并设置打开书籍时是否默认继续听书。
- 历史页新增「阅读」分组（按天展示阅读与听书记录，点击可继续阅读）；统计页新增「阅读时长」卡片，分别统计静读与听书时长。
- 数据备份范围扩展至本地书库、阅读进度、阅读排版、阅读历史与听书设置，重装后可完整还原（书籍文件本身不参与备份）。
- 听书统计页新增「最近记录」：可查看最近读过的书与听过的专辑，一键回到上次的位置继续，也支持清空记录。
- 书架顶部新增续读提示，直接接着上次的进度继续阅读或收听。

### 功能优化

- 听书与音乐播放共用同一套后台媒体控制，切换时不会互相抢占；来电或其他应用打断后会自动暂停，恢复后可继续朗读。
- 关于页「检查更新」的版本基准随安装包版本自动更新。
- 听书播放页重新排版：语速、朗读方式、睡眠定时与章节切换收为工具栏小图标，点开才展开设置弹层；睡眠定时改用滑杆按 5 分钟步进调节；「回到阅读」在播放键左侧，「章节」在右侧。
- 阅读页翻页改为跟手拖动，松手后回弹或翻到下一页，不再瞬间跳页。
- 主题精简为三套，不再提供暗夜摩卡、暗夜金橙与春日活力。
- 设置页移除「下载」类目与「后台自动播放下一章」，「仅 Wi-Fi 下载」开关移到下载管理页，修改后可正常保存。

### 问题修复

- 从阅读页开始朗读、以及从朗读跳回原文时，两边的位置始终一致。
- 朗读读到页末会继续往下读，不再回到本页开头。
- 本地导入的 EPUB 会显示书籍的真实封面，此前导入的书打开书架后也会自动补全。

## v1.3.2（2026-11-03）

### 新增功能

- 设置页新增「数据备份」：可将设置、书架收藏、收听历史与进度、收听统计一键打包成备份文件导出，支持设置密码加密，用于换机或重装后的数据迁移。

### 功能优化

- 原「WebDAV 云同步」已下线，数据迁移改为本地备份文件方式，不再需要网盘账号；导入备份前会逐项列出将被覆盖的数据供确认，还原完成后无需重启立即生效，取消或失败均不影响本机现有数据。

### 问题修复

- 无。

## v1.2.0（2026-10-30）

### 新增功能

- **客户端检查更新（GitHub Releases）**：关于页新增「检查更新」入口，手动触发；Android 走完整闭环（检查 → 下载 → 安装），Web 仅保留仓库链接不接逻辑；**永不强制**，任何阶段可取消/关闭。
  - 数据源 `api.github.com/repos/51www/kele-audio/releases/latest`，带 `User-Agent`、连接 12s / 传输 20s 超时；版本比较去 `v` 前缀与 `-beta` 后缀按段数值比较，同版本/更旧一律不提示。
  - 产物选择：Android 优先 `*-android-universal.apk`，兼容历史 `app-release.apk`，排除 `.aab`。
  - 国内镜像加速：下载回退顺序「镜像在前 → GitHub 官方直连兜底」，接口顺序「官方优先 → 镜像兜底」；支持 `--dart-define=UPDATE_MIRROR=https://你的镜像/`（逗号分隔，排最前），镜像失效无需发版。
  - 安全：下载完成后用 GitHub asset 的 `sha256:` digest 校验文件哈希，不匹配换源重下，digest 缺失则跳过校验不阻断。
  - 影响范围：平台 Android / Web；新增文件 `lib/features/update/*`；新增依赖 `package_info_plus`；Android 新增 `REQUEST_INSTALL_PACKAGES` 权限与 `FileProvider`（`${applicationId}.fileprovider`），`res/xml/file_paths.xml` 覆盖 files/external-files/cache 目录。

### 功能优化

- 无。

### 问题修复

- 修正「关于 / 版本」硬编码版本号与 pubspec 不一致（原硬编码 `1.0.0`，实为 `1.1.0`）：改为运行时读取 `PackageInfo` 真实版本作为比对基准，避免「已是最新」误判及自报有新版本。

## v1.1.0（2026-10-29）

### 新增功能

- 播放页新增「文稿」：功能图标带的「播放顺序」按钮替换为「文稿」开关，打开后上区（封面）切换为「顶端固定标题 + 可滚动文稿」浏览视图（仅浏览，不联动播放进度）；文稿来自 B 站人工 / AI 字幕（AI 字幕需绑定 B 站账号），仅内存缓存不落库，无字幕章节显示「本章暂无文稿」空态。
- 播放模式不再支持播放页切换，统一由设置页「默认播放模式」决定。

### 功能优化

- 专辑详情页「播放全部」：点击后立即进入播放页，装载/取址与页面转场并行进行，消除「播放条先弹出 → 再跳转播放页」的两段式突兀体验；播放页装载期间显示「正在准备播放…」过渡态，不再闪过「未选择内容」空态。
- 统一播放入口语义：只有专辑详情页「播放全部」会跳转播放页；书架页（在听/收藏）、历史收听页、详情页点单集等入口均改为就地弹出播放条并直接播放，不再自动跳转页面。进入播放页统一通过点击播放条完成。
- 桌面端与移动端表现一致。
