**风格关键词**：暖奶油纸感背景、复古书卷、低饱和、琥珀点缀、柔和无阴影压迫感、文艺沉静

**提示词**：

```

图标为深棕描边或实心，播放键为纯黑圆形+白色图标，形成唯一高对比锚点；
```

## 备注

- 提取原则：只保留风格类信息（配色、材质、字体气质、光效、氛围），布局与功能未纳入。
- 七个主题均已实现为**可切换的自定义皮肤**（设置页「主题」，实现见 `lib/app/theme/`）。
  **不区分「一般模式主题 / 儿童模式主题」两套槽位**，全应用只有一个主题，可自由切换任意预设：
  - 默认主题：主题 1（暖纸书卷）；
  - 进入儿童模式时自动套用主题 4（明橙新绿·春日活力），之后仍可手动切到任意其他主题，儿童模式不锁定主题；
  - 退出儿童模式不强制换肤，保持当前所选；
  - 主题 3、6、7 为深色皮肤（暗夜金橙 / 静夜墨灰 / 暖夜摩卡），其余为亮色皮肤；主题 5（薄荷春芽）为备选清新皮肤。
- 落地约束：七套皮肤只换颜色，圆角/间距/字阶全主题共用（一致性）；
  文字与底色对比度按 WCAG AA（≥4.5:1）校验（`test/theme_contrast_test.dart` 守卫）。
