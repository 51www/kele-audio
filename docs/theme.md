## 主题 1：暖纸书卷（Warm Paper / Vintage Book）

> 源图：`ScreenShot_2026-10-23_150609_889.png`

**风格关键词**：暖奶油纸感背景、复古书卷、低饱和、琥珀点缀、柔和无阴影压迫感、文艺沉静

**提示词**：

```
暖奶油色/米白纸感背景，整体低饱和暖色调，呈现复古书页与牛皮纸的质感；
深棕炭灰色文字，字重对比明显，标题带有手写衬线/书法气质，正文为圆润无衬线；
卡片采用浅米色微渐变底色，大圆角（约 16-20dp），极浅弥散投影，边缘柔和不割裂；
点缀色为琥珀橙/蜜糖金渐变，用于主行动按钮（胶囊圆角+暖光晕），克制且温暖；
图标为深棕描边或实心，播放键为纯黑圆形+白色图标，形成唯一高对比锚点；
背景中隐现极淡水墨/羽笔插画元素，似书页暗纹；
氛围关键词：温暖、沉静、纸质、人文、低刺激、适合长时间阅读收听、
类纸张护眼模式、Vintage Editorial、Warm Minimalism、Cream & Amber Palette。
```

**调色参考**：

| 角色 | 色值方向 |
|---|---|
| 背景 | #F7F1E7 奶油米白 |
| 卡片 | #FBF7EF → #F3E9D8 微渐变 |
| 主文字 | #3D362C 深棕炭 |
| 次文字 | #A39A88 暖灰 |
| 强调色 | #E8B04B → #D98E28 琥珀金渐变 |
| 主按钮 | #111 纯黑（播放键） |

## 主题 2：青铜书架·暖知（Bronze Library / Knowledge Warmth）

> 源图：`ScreenShot_2026-10-23_150719_992.png`

**风格关键词**：深棕青铜 3D 书架插画头图、电影感暖光、奶油白卡片区、橙红渐变行动点、知识殿堂氛围

**提示词**：

```
头图为深棕青铜色调的 3D 渲染插画：层叠书本如书架殿堂，逆光/侧光电影感布光，
暗部沉稳、高光泛金，营造"知识殿堂"仪式感；插画中点缀飞鸟剪影与小人物，增加叙事感；
内容区回归浅色：奶油米白背景 + 纯白大圆角卡片（约 14-18dp），卡片投影极浅、干净通透；
标题字重粗、深棕近黑，正文暖灰，层级对比清晰；小标题带衬线人文气质；
行动点采用高饱和橙红渐变胶囊按钮（内嵌播放三角图标），是全页唯一高饱和色；
积分/奖励元素用金橙菱形宝石符号点缀，呼应"成就/获得感"；
图标为棕橙双色描边风格，底部导航选中态为棕橙渐变圆底图标；
氛围关键词：知识殿堂、温暖专业、收获感、品质教育、Premium Learning、

```

## 主题 4：明橙新绿·春日活力（Bright Orange-Green / Spring Promo）

> 源图：`ScreenShot_2026-10-23_150835_953.png`

**风格关键词**：浅色底、橙绿渐变插画横幅、扁平双色图标、金黄胶囊标签、促销热闹感、白卡片干净排布

**提示词**：

```
整体浅色明快基调：纯白内容底 + 顶部大面积渐变横幅（暖橙天空 → 嫩绿草地，春日氛围），
横幅内为扁平插画：书本、飞鸟、云朵，色彩鲜亮饱和、童趣轻快；
横幅标题使用超粗展示字体，数字/关键词为橙红大字，冲击力强；
主行动按钮为红橙渐变胶囊（圆角全圆），白色粗体文字；
内容区纯白卡片（圆角 12-14dp），配浅灰描边或极浅投影，干净透气；
搜索条为胶囊圆角、白底浅灰边，右端嵌金黄渐变"搜索"按钮；
功能入口图标为扁平双色/多色插画风（橙黄黑组合），排布规整；
分区标题左侧带橙色竖条强调，右侧配浅灰辅助链接；
筛选标签为金黄渐变胶囊（小号），选中态高饱和；
封面缩略图带角标（红色"限免"标签、红底白字折扣圆标），促销感强；
底部播放条为深灰圆角悬浮胶囊，左嵌彩色圆形封面，整体悬浮于浅色页面之上；
氛围关键词：活力促销、春日明快、Bright & Cheerful、Orange + Fresh Green、
Flat Illustration、热闹不杂乱、适合大众向内容平台。
```

**提示词**：

```
整体薄荷绿渐变背景（浅绿 #CDE9C8 → 中绿 #9FD4A6，通透清爽，春日感）；

卡片小节标题用绿色渐变粗体字，左右各一枚粉色四角星芒（✦）装饰，俏皮可爱；
```
